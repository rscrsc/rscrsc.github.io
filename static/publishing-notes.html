基本文本

普通段落保持接近 GNU 手册的阅读密度，同时用接近 Vim 文档站点的克制绿色作为强调色。这里包含 斜体、粗体、删除线、make all、CO2 与 x2。链接既可以指向 Pandoc，也可以指向本页的数学公式。

行内公式示例为 \sigma^2 = \operatorname{Var}(X)，它不会请求任何 CDN。

静态站点的关键不是“没有 JavaScript”，而是正文和路由不依赖 JavaScript。这里的 JavaScript 只负责渐进增强：标签筛选和数学渲染。

数学公式

行间公式使用标准 Pandoc Markdown 语法：

P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}.

再给出一个带求和与极限的式子：

\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i, \qquad \lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n=e.
